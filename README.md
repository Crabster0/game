Python hra

Dinterová, Plešáková

Naším cílem je vytvořit textovou adventurní hru v Pythonu s převážně lineárním příběhem, ASCII grafikou a jednoduchým webovým rozhraním. Hráč bude postupovat příběhem, prozkoumávat prostředí, vybírat z nabízených možností a plnit úkoly. Databáze bude sloužit k ukládání herního postupu a případně uživatelských účtů.

Nejprve vymyslíme příběh, jednotlivé scény, možnosti. Poté vytvoříme schematický graf děje v https://www.drawio.com/. Poté naprogramujeme základ hry v Pythonu a vytvoříme databázi v SQLite, pro ukládání postupu. Pro webovou aplikaci využijeme Flask, který propojí Python s HTML a CSS. ASCII grafiku vytvoříme pomocí img to ASCII webů. Nakonec hru otestujeme, opravíme chyby a drobnosti.

Z finanční stránky projekt lze vytvořit téměř zdarma. Python, Flask, SQLite, Visual Studio Code i GitHub mají bezplatné možnosti využití. Pokud budeme hru provozovat online, můžeme využít bezplatný hosting, případně později placený hosting v ceně přibližně 100–300 Kč měsíčně.

Očekáváme, že si procvičíme programování, práci s databází, tvorbu webových aplikací a spolupráci na větším projektu. Hlavním cílem bude vytvořit funkční a hratelnou hru, kterou si bude možné spustit přímo v internetovém prohlížeči.
